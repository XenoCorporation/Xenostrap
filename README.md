# Xenostrap

Xenostrap là một custom launcher cho Roblox, được phát triển như một bản nâng cao từ Bloxstrap. Đây là giải pháp thay thế mã nguồn mở giúp bạn tùy chỉnh trải nghiệm Roblox với nhiều tính năng mở rộng mà launcher gốc không có.

## Tính năng chính

### Fast Flags & Cấu hình
- Editor mạnh mẽ với hàng ngàn tham số Roblox
- Hệ thống preset thông minh cho các cấu hình phổ biến
- Quản lý nhiều profile cấu hình khác nhau
- Channel management để chuyển đổi giữa các phiên bản Roblox khác nhau

### Tùy biến giao diện
- Custom themes với hệ thống theme editor tích hợp
- System mods để thay đổi giao diện Roblox
- Animation preview để xem trước các hiệu ứng
- Template từ cộng đồng để dễ dàng chia sẻ và sử dụng

### Tối ưu hiệu năng
- Asset proxy để giảm tải khi tải tài nguyên
- Texture stripping để giảm bộ nhớ và tăng FPS
- CPU core limiter để kiểm soát việc sử dụng CPU
- DNS resolver tùy chỉnh để giảm lag kết nối

### Discord Rich Presence
- Hiển thị trạng thái chơi game lên Discord
- Thông tin server và activity chi tiết
- Tùy chỉnh nội dung hiển thị theo ý muốn

### Launch Hub
- Khởi chạy cả Roblox Player và Studio từ một nơi
- Launch profile để cấu hình nhanh cho từng trường hợp
- Deeplink support để mở trực tiếp từ link
- Lịch sử server đã tham gia

### Quản lý tài khoản
- Quản lý nhiều tài khoản Roblox cùng lúc
- Friend list tích hợp
- Avatar customization tools
- Outfit manager để quản lý trang phục

### Integrations
- Hỗ trợ RiShade cho đồ họa nâng cao
- Rojo integration cho Roblox Studio
- Extension system để thêm các plugin
- Asset tools cho developer

### Cross-platform
- Hỗ trợ đầy đủ Windows, Linux, và macOS
- Trải nghiệm đồng bộ giữa các nền tảng
- Optimizations riêng cho từng hệ điều hành

### Công cụ tiện ích
- Anti-aliasing options
- Animation viewer
- Mesh viewer
- Image processing tools

## Cài đặt

### Yêu cầu hệ thống

**Windows:**
- Windows 10 1809 trở lên
- .NET Desktop Runtime 6.0 trở lên
- 2GB RAM tối thiểu (4GB khuyến nghị)
- 500MB ổ cứng trống

**Linux:**
- Ubuntu 20.04 hoặc tương đương
- .NET Runtime 6.0 trở lên
- Thư viện graphics drivers tương thích
- 2GB RAM tối thiểu (4GB khuyến nghị)
- 500MB ổ cứng trống

**macOS:**
- macOS 10.15 Catalina trở lên
- .NET Runtime 6.0 trở lên
- 2GB RAM tối thiểu (4GB khuyến nghị)
- 500MB ổ cứng trống

### Cách cài đặt

1. Download phiên bản mới nhất từ [GitHub Releases](https://github.com/XenoCorporation/Xenostrap/release)
2. Chạy file installer
3. Chọn thư mục cài đặt (mặc định: C:\Program Files\Xenostrap)
4. Chọn các component muốn cài
5. Hoàn tất cài đặt và khởi động Xenostrap

### Lưu ý quan trọng
- Xenostrap sẽ thay thế launcher gốc của Roblox
- Bạn có thể gỡ cài đặt bất cứ lúc nào để quay về launcher gốc
- Dữ liệu Roblox của bạn không bị ảnh hưởng
- Khuyến nghị tạo backup trước khi cài lần đầu

## Cấu hình cơ bản

Sau khi cài đặt, bạn nên:
1. Kiểm tra tab Settings để cấu hình cơ bản
2. Cập nhật Roblox phiên bản mới nhất nếu cần
3. Thử các Fast Flags preset để tối ưu hiệu năng
4. Tùy chỉnh theme theo sở thích
5. Kết nối Discord Rich Presence nếu muốn
